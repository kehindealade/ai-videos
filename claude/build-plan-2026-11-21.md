Trigger: when Kenny says "continue the video build" in a new conversation, start the first conversation below whose Status is not DONE (or the number he names). At the end, set its Status to DONE with the date and what was delivered.

Build-day setup note (21 Nov 2026): a fresh workspace has no pycairo, kokoro-onnx or voice model. Install with `pip install --break-system-packages pycairo kokoro-onnx soundfile` and download kokoro-v1.0.onnx and voices-v1.0.bin from github.com/thewh1teagle/kokoro-onnx releases (model-files-v1.0) into /root/kokoro (curl -L works through the proxy). Reusable engines: claude/money-map-bf-engine/ (bf_common.py helpers, bf_short.py, bf_reel.py), claude/why-expensive-engine/ (wx_common.py, wx_engine.py generic runner, ink.py episode; see its README), claude/money-map-iou-engine/ (long video in 2 parallel render parts, plus Shorts; see its README) and claude/christmas-engine/ (story film with no narrator: figures, scenes, score, Shorts, thumbnail; see its README). Music-only Reels need no Kokoro: pip install pycairo soundfile scipy numpy; fonts Poppins, Inter and Anton are preinstalled; Rounded Mplus 1c ExtraBold, Share Tech Mono and Architects Daughter come from raw.githubusercontent.com/google/fonts/main/ofl/<family>/ into ~/.fonts (then fc-cache -f). Do not name a Python file numbers.py (it shadows the stdlib and breaks numpy).

Fact-check rule learned 21 Nov 2026: re-verify every comparison in a script on build day. Script 5's "ink costs more per ounce than silver" had become false (silver rose to about $50 to $65 an ounce), so the hook was changed. Script 4's "$39 trillion" was also stale ($40.7T on 18 Nov 2026).
