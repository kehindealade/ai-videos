# AI Videos: Money Map and Small Win Films

Code-made videos for two channels: Money Map (finance explainers) and Small Win Films (animated story films and relatable Reels). Everything is drawn, animated and scored in Python.

Start with START-HERE.md. AI agents: read AGENTS.md (GEMINI.md and CLAUDE.md point to it).

- START-HERE.md: what this is, reading order, pipeline
- STATUS.md: posted, scheduled, open work
- ENGINE-INDEX.md: every engine and its render command
- MANIFEST.md: every exported file and its status
- memory/: project memory notes (preferences, channel history, title plan, timetable)
- claude/: all project docs, logs and engines (paths kept as in the original project so cross-references work)
- setup.sh, requirements.txt, render.ipynb: setup and rendering
